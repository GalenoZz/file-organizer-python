📁 Downloads & File Organizer in Python

Um script automatizado em Python desenvolvido para organizar diretórios e pastas de downloads de forma prática e rápida, separando arquivos por suas respectivas extensões (documentos, imagens, executáveis, áudios, etc.).

🚀 Funcionalidades

Organização Automática: Varre o diretório indicado e agrupa arquivos em pastas específicas.

Mapeamento por Extensão: Classifica automaticamente tipos comuns de arquivos (ex: .pdf, .png, .exe, .zip, .mp4).

Automação & Produtividade: Elimina a poluição de arquivos acoplados na pasta de Downloads de forma instantânea.

🛠️ Tecnologias Utilizadas

Python 3.x

Módulos nativos (os, shutil, pathlib) — sem necessidade de instalações externas.

🔧 Como Executar o Projeto

Clone o repositório:

git clone https://github.com/GalenoZz/file-organizer-python.git


Acesse a pasta do projeto:

cd file-organizer-python


Execute o script:

python main.py


(Substitua main.py pelo nome exato do seu arquivo .py)
